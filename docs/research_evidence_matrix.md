# Research evidence matrix — the V3 programme by scientific question

Organised by question, not by experiment id. Every number is quoted with the artifact it comes from;
where a number is a descriptive result rather than a gate outcome, it says so. Column semantics:

- **Research question / Hypothesis** — the question and what was predicted;
- **Primary experiment(s)** — the runs that bear on it;
- **Dataset / evaluation unit** — the population and the unit of analysis;
- **Key result** — the measurement;
- **Uncertainty / robustness** — intervals, replication, known weaknesses;
- **Supported conclusion** — what the evidence licenses;
- **Unsupported stronger claim** — the reading that is *not* licensed;
- **Status** — closed / open.
